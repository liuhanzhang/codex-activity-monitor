# GUI 重设计：产品需求

日期：2026-10-16。状态：本章需求已实现并更新本机 App；验收证据及剩余环境边界见[实施结果](implementation-results.md)。视觉材料见[设计细节](design-spec.md)，修改顺序见[实施计划](implementation-plan.md)。

## 1. 目标与范围

1. 减少展开面板的面积、空白和低频信息，使当前聊天、动作与生成速度容易扫描。
2. 菜单栏以 `999 T/s` 为基准保持紧凑，更长数值才扩宽。
3. 单会话通过动效区分思考与执行；多会话保持整体吞吐量视角。
4. 面板始终锚定菜单栏下方，并具有可靠的收起行为。

范围为现有 macOS 26+ 原生 GUI 的重设计。保留 Python 核心、SwiftUI / AppKit 和当前配置管理。TUI 的文案与格式、指标计算定义、接入与卸载机制、公开发行不在本轮修改范围。不新增长期历史、曲线、聊天跳转、审批或用户输入操作。

## 2. 菜单栏

### 2.1 宽度与速度格式

| 编号 | 要求 |
| --- | --- |
| M1 | 菜单栏基准宽度按实际 12 pt 字体测量 `999 T/s` 并加左右各 2 pt 留白，当前为 47 pt。更长的速度数值按实际文本宽度扩展，回到三位数以内或图标 / 未知状态时恢复基准宽度；极端异常值保留有界降级。 |
| M2 | 数字使用等宽数字；图标态居中。三位数以内保持同一基准宽度，不以补空格模拟；只在更长数值需要时改变状态项长度。 |
| M3 | 全部 GUI 速度统一为整数、大写 `T/s`、无 `≈`，例如 `48 T/s`、`0 T/s`。非负有效数值四舍五入，原始快照保留原精度。 |
| M4 | 生成态仅展示数字和单位，不附加波形、打字光标、笔尖或火苗。可靠快照明确 `reason=idle`、主聊天数为 0 且存在已连接后端时显示静态沙滩图标；灰度比格小狗仅保留为仓库素材和开发预览，普通界面不提供切换选项。 |
| M5 | 空值、无穷、非法值、断连、过期或不完整观测保持 `—`；未知不能转换成零。极端长数值不得撑宽、覆盖相邻图标或通过截断显示错误数字；需有固定区域内的降级表示及完整值悬停说明。 |

移除约等号是展示变化，不把本地窗口估算重新定义为服务端精确吞吐量。估算口径和 `Output` 包含 `Reasoning` 的解释通过悬停说明提供，保留底层质量标志。

### 2.2 状态决策

按以下顺序判断，状态以可信活动证据为依据，不解析中文标签、不以速度是否为零猜阶段：

| 条件 | 菜单栏显示 |
| --- | --- |
| 快照过期、断连、身份 / 活动观测不可靠、总速度覆盖不完整 | `—`，停止进行中动画；面板说明原因 |
| 至少两个活跃主会话 | 总生成速度，完整观测且无生成时为 `0 T/s`；不显示思考 / 执行动画 |
| 只有一个活跃主会话，存在当前生成活动 | 总生成速度，例如 `48 T/s` |
| 只有一个活跃主会话，无当前生成，存在确认执行中的工具 | 小锤子敲击动画 |
| 只有一个活跃主会话，无当前生成或执行，存在确认思考中的活动 | 三个小点位置固定，依次明暗变化 |
| 没有活跃会话，可靠快照明确空闲且存在已连接后端 | 静态沙滩图标，保持 47 pt 基准区域 |
| 只有一个活跃主会话，处于等待、暂停、准备或其他未分类阶段 | 不播放思考 / 执行动画；确认无生成时显示 `0 T/s`，生成可用性不确定时显示 `—`；具体阶段在面板显示 |

生成、执行、思考并存时采用“生成 → 执行 → 思考”的优先级。此优先级只用于菜单栏单状态，不隐藏详情中的并行动作。等待审批、请求用户输入、自动审核、重试和工具调用准备都不能自动等同于确认执行。

当前生成继续沿用既有 `text / plan / summary / tool_input` 独立流定义，包括可见推理摘要，不改变计量口径。菜单栏必须区分“仍在活动的生成流”和“上一阶段滑动窗口的残余速度”：活动生成中的短暂停顿不切换图标；生成已明确结束、进入工具执行后，不等待旧数值衰减为零才切换。仅有 reasoning 活动而没有当前可观测生成时才用思考动画。细分流生命周期由核心投影，不由 GUI 依据静默时长推测。

对短暂中间状态做有限防抖，保持显示稳定；完成、暂停、失败、断连和过期立即生效，不能为播放完整动画延迟停止。

### 2.3 活跃会话与子代理

- 按逻辑主聊天分组，任务仍在进行或仍有可信活跃工作才算活跃；空闲、最近完成和仅保留在列表中的聊天不计数。
- 有明确父子关系的子代理归父聊天。同一根下多个活跃子代理仍是一组；父聊天已结束但子代理仍在工作时，该组仍活跃。
- 分组依据稳定身份和明确父子关系，不按项目名、聊天标题、文本相同或可见行数判断。关系缺失、跨 scope、冲突或成环时保守视为独立组。
- 计数覆盖全部已接入的可信活动，不能因列表过滤、折叠或父聊天不在最近项中而漏算。
- 子代理的独立生成流仍参与原有总速度汇总，父子镜像不重复相加。新增“主会话数”不改变旧 `active_thread_count` 的 Thread 计数语义。

## 3. 展开面板

| 编号 | 要求 |
| --- | --- |
| P1 | 约 420 pt 宽；根据内容收缩和增高，超过当前屏幕可用高度上限后仅列表区滚动。无聊天时使用紧凑空状态。 |
| P2 | 顶部一行包含连接状态、总生成速度及唯一设置入口；不保留大装饰图标、大标题和重复解释。面板总速始终为数值或 `—`，不因菜单栏显示动画而被替换。 |
| P3 | 聊天默认两行：第一行标题与实时生成速度，第二行项目、当前动作与动作耗时；名称省略时可以查看完整名称。 |
| P4 | 点击聊天按需展开本回合 Output / Reasoning、最近推理均速、工具活动和子代理；详情保留并行活动及未知值。 |
| P5 | 活跃聊天优先且同组排序稳定；不因每秒速度或最新进度更新而交换位置。新增 / 完成等生命周期变化可以调整分组。 |
| P6 | 最近完成默认折叠，沿用最近约 10 分钟最多 10 项的边界；空闲项不能被误标为完成。展开状态以稳定聊天身份保存。 |
| P7 | 底部仅保留简短活动会话数量等必要状态，不重复管理入口。数量与菜单栏使用相同主会话口径。 |
| P8 | 未连接、部分观测、过期、配置待生效及管理失败等原因必须可发现；正常时收起解释，异常时用简短提示，必要时展开查看。 |

Output / Reasoning 的包含关系、最新有效推理均速保留、未知耗时等沿用既有语义。行内耗时代表当前动作持续时间，不能被当作整轮任务耗时。

## 4. 位置、焦点与收起

- 面板锚定当前菜单栏按钮，在菜单栏下方展开，不覆盖按钮或菜单栏。聊天详情展开时向下增高，保持顶部锚点稳定。
- 靠近屏幕边缘时避让；以按钮所在显示器计算屏幕与可用区域，兼容缩放、菜单栏自动隐藏及全屏场景。
- 点击面板外，包括桌面空白或其他应用：收起；再次点击菜单栏入口：切换；`Esc`：收起；切换到其他应用：收起。
- 点击面板内部留白不收起。使用自身设置菜单、恢复确认框等关联界面时不误判为外部点击或失焦关闭。
- 外部点击照常交给用户点击的目标，不吞掉事件、不抢回焦点。收起仅隐藏面板；菜单栏与采集继续运行。
- 常用操作支持键盘焦点与可访问名称；状态表达不能只依赖颜色或每帧动画。

## 5. 设置、动效和生命周期

顶部设置菜单集中容纳配置 / 修复接入、恢复配置、登录启动、退出及系统授权入口。保留现有管理操作禁用条件、等待清理状态、错误反馈和恢复确认。普通查看面板不触发配置或恢复。

思考动效为三个小点在固定位置从左到右依次明暗变化，不跳动、不缩放；执行动效为单色小锤子的抬起、敲击和回弹。两种动效均静音、轻缓、范围受限；不搬入 Xcode 的完整彩色 App 图标。跟随所在屏幕同步刷新，高刷新屏优先 120 fps，动画周期和停顿不随帧率改变。动画仅在对应可靠状态持续时播放，收起面板后菜单栏仍按当前状态工作。减少动态效果时保留静态形状与可访问状态说明，并停止动画回调。归档的小狗实验为 8 帧、每帧 0.2 秒的 1.6 秒循环，实际绘制高 18 pt，保留透明背景、不透明白毛和灰色花色。

GUI 数据刷新和动画帧率分开：动画不提高采集、分词或管理命令频率。退出 App、暂停采集、恢复配置等生命周期行为继续遵循[第 06 章](../06_gui_app_options_and_decisions/requirements.md)。

## 6. 验收要求

| 编号 | 必须验证的行为 |
| --- | --- |
| U1 | `0 / 9 / 48 / 126 / 999 T/s / —`、思考和执行切换时保持基准宽度；四位及更长数值按需扩宽，回落后收窄；极端数值有明确降级。 |
| U2 | GUI 全部速度为整数、大写单位、无约等号，生成态无附加图标；原始精度、估算标志及计量不变。 |
| U3 | 单会话生成 / 思考 / 执行分别正确；多个主会话始终显示总速；父子分组与镜像去重不冲突。 |
| U4 | 活动生成短暂停顿、上一阶段残余速度、准备 / 暂停 / 等待、断连与过期不会触发错误动画。 |
| U5 | 少量聊天时面板缩短；长标题、详情、子代理和多条活动可读，超过高度上限可以滚动。 |
| U6 | 新增 / 完成导致合理分组变化；每秒指标更新不重排聊天、不丢展开状态或滚动位置。 |
| U7 | 面板位于菜单栏下方，展开向下增长；当前机器上的边缘、多显示器 / 缩放及自动隐藏场景按实际覆盖记录。 |
| U8 | 外部空白、其他应用、重复点击入口、`Esc`、应用切换均可靠收起；内部留白、设置菜单及恢复确认不误关闭。 |
| U9 | 收起后采集继续；退出、配置、恢复、延后清理和管理失败反馈沿用现有行为。 |
| U10 | 动效轻缓且在失效状态停止；减少动态效果、浅 / 深色、键盘与可访问名称可用。 |

验收分别记录模型 / 契约测试、HTML 设计预览、原生固定快照、本机实际使用的证据。截图不能证明动画节奏、外部点击或采集生命周期，不能以任一层的通过替代其他层。
