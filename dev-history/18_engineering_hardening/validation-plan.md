# 验证与验收计划

状态：分阶段执行中。这里保留完整检查矩阵与完成标准；已通过范围以[实施记录](implementation-results.md)及其数据附件为准，不能把整个矩阵预填为通过。基线历史见[第 17 章验证](../17_review_and_refactor/validation.md)，后续菜单栏证据见[回归调查](../17_review_and_refactor/status-regression.md)。

## 验证层级

1. **契约和状态规则**：合成输入验证身份、版本、终止、作用域、未知和兼容。
2. **隔离进程集成**：临时 runtime、真实 Unix socket／pipe／独立 child、可注入磁盘 writer 和时钟；不接管日常 Codex。
3. **原生 GUI**：同一真实接收路径到 store 和 AppKit draw；窗口、阅读位置、语言、辅助功能分开验收。
4. **规模与自然使用**：明确硬件、负载、版本、样本、持续时间与未覆盖范围；不把合成输入或一次构建当作自然使用。

测试等待语义条件或同步屏障，并设置截止时间；不依赖恰好睡过某个旧刷新周期。只有实际变更、失败或兼容缺口需要扩大回归范围。

## P0：结束状态与历史交接

| 场景 | 通过条件 |
| --- | --- |
| 完整新回合，短正文与较长正文 | 无中途重载；可对齐最后 delta、item／turn 完成、GUI 状态，记录是否仍出现约 2 秒滞留 |
| 主回合结束后 `ephemeral=true` 任务继续 | 正常聊天聚合／菜单保持相应空闲；原始临时线程观测仍可诊断 |
| 临时分类未知／普通隐藏聊天／真实子智能体 | 不按名称排除；真实活跃工作仍贡献状态，父子范围正确 |
| 未关联输出已经明确结束 | 可保留身份恢复队列；已结束输出不持续阻止当前速率覆盖 |
| JSONL 迟到、完整交接 | 实时终止可即时结束当前指示；有效历史接管后实时补充退役，不重复活动、不恢复历史实时速度 |
| 暂不可读、部分末行、确定替换／截短 | 三者结果不同；无读取成功证据不当作删除，确定失效时不保留旧历史结论 |

同一时钟与明确 ID 对齐：源事件／source timestamp、bridge 观察、Engine 入队／处理、状态投影、发送／发布、GUI 接收／应用、AppKit draw。GUI draw 只证明绘制回调，不等同于物理屏幕呈现；Desktop 完成通知也不独自证明正文最后一个像素的时间。

自然样本逐步覆盖短／长、工具与真实子智能体回合，建议累积至少 10 个完整回合；不为凑数额外调用模型。报告每个阶段延迟与异常样本，不只报一个平均值。不能因本轮跨重载而静默清除 gap。

## EH01：通信、健康、背压与存档

| 场景 | 通过条件 |
| --- | --- |
| 一帧拆成多次读取，多帧合并读取，UTF-8 被拆开 | 只对完整有界帧解码，顺序及内容正确 |
| 帧过大、无换行、无效 JSON／版本 | 有界拒绝，其他连接和 collector 继续，不无限保留接收字节 |
| 刚发送旧状态后立刻 turn end | 状态变化走下一采样，不等待普通 1 s 数值发布；受控单聊天本机回归以 0.75 s 为截止目标 |
| 存档 writer 被屏障阻塞至少 30 s | 阻塞期间新事件、状态与心跳继续；测量事件处理、GUI 应用和主转发，不能只检查进程尚在 |
| ENOSPC／权限失败，之后恢复 | 累计诊断、有限退避，实时覆盖不被磁盘故障冒充；恢复后写最新检查点 |
| 只读订阅者暂停读取至少 60 s，GUI 租约正常 | 待发帧数与总字节有界；慢端超时退出，正常端仍更新 |
| 事件循环停滞、发送 worker 仍有心跳 | tick 进展过期使 UI 保守显示，不被“socket 还连接”误报健康 |
| 客户端暂停后读到积压心跳 | 过期／不匹配 nonce 不续期健康，恢复须取得新响应和对应完整状态 |
| 旧序号、旧实例／旧 Task 的迟到状态 | 无法覆盖新实例／最新代际；新连接首先拿到完整状态 |
| 仅 GUI 断开并重连，collector 未断流 | 显示连接状态变化；不制造源 gap，也不补造 GUI 未显示的中间动画 |
| bridge 断开／collector 重启 | 新状态保留真实 source gap；历史能补事实，不能补接收速度 |
| GUI 正常退出、崩溃、读者仍连接 | 只有所属 GUI 能续期／释放租约；普通订阅者不维持观察；期限后安全停采 |
| management 查询或 observation 文件 I/O 阻塞 | IPC 心跳与状态任务独立；新版 bridge 的 `offer()` 无磁盘／socket 等待，原始 stdio 继续 |
| 正常关闭且存档卡住 | 保存等待和进程退出有界，解释器无隐式无限 join，锁不会提前交给另一 writer |
| GUI／CLI／fixture、旧版本组合 | 新读端以 IPC 判断健康；显式文件路径按离线时钟；不支持版本有明确降级 |

0.75 s 是受控回归的工程目标，运行结果须记录硬件和负载，不宣称所有真实环境都满足该时延。实际用户体验同时记录 AppKit draw 与自然样本；超出目标时分析瓶颈，不能仅放宽 sleep 取得通过。

## EH02：子进程可靠性

使用仅属于测试的 child fixture，所有终止测试的 PID／进程组都与日常 Codex 隔离。

| 场景 | 通过条件 |
| --- | --- |
| stdout/stderr 同时超过管道容量 | 两端持续排空，无相互等待 |
| stdout 超上限、stderr 持续输出 | 内存有界；stdout 超限明确失败；stderr 尾部有限且继续 drain |
| child 忽略 SIGTERM | deadline／取消后升级终止，回收在策略宽限内完成 |
| 后代继承 pipe、直接 child 已退出 | 调用不无限等待 EOF；所属进程范围按设计清理 |
| 启动前取消、启动时取消、自然退出与 deadline 同时发生 | 单次完成、无旧 timer 副作用、FD／任务释放 |
| 输出不是 JSON／非零退出／启动失败 | 失败种类明确且中英文可显示，不应用半段内容 |
| 管理命令生效后才被取消／超时 | 重新核对真实管理状态，不把副作用当作已经撤销；不误杀独立 collector 或回滚后续用户变更 |
| 选择切换后旧操作失败或成功 | 两种结果均不会覆盖新选择，旧 loading 不阻止新请求 |

退出时间以操作 deadline、终止宽限和 drain 预算组合判断，额外记录调度误差；测试建立“fixture 已进入目标状态”的屏障后再触发取消，避免把没启动成功当作终止通过。

## EH03：分页同版本

- 第一页与后续页分别由新建 provider／独立 CLI 请求读取，稳定内容 token 必须一致。
- 在两页之间分别做无关行追加、当前 section 尾部追加、原位等长改写、文件替换、截短与 live→history 交接；只有满足原阅读快照规则的页面可以合并。
- 在生成摘要与切页之间、引用读取前后注入源变化；响应不能组合来自两个内容版本的摘要和文本。
- 错 scope/thread/turn/phase/section/token、过大长度、负偏移、非前进游标、错误版本均拒绝。
- 使用中文、emoji、组合字符、换行和 JSON 原始工具结果；以服务器 code point 游标验证完整重组，不能按 Swift `String.count`／UTF-16 长度推导。
- 验证版本变化和来源丢失保留已读内容／滚动位置；重新加载、选择切换、语言切换、独立查看器复用时旧请求不能污染新状态。
- v1 初始展示与禁止无版本续页、v2 正常读取、旧 GUI 对 v2 的明确拒绝分别覆盖；Snapshot／timeline 的既有版本不受误升级。
- 统计每页读取字节、引用次数与摘要时间。页 token 计算不得每次扫描整个聊天；后续 EH04 提供大 section 的资源依据。

## EH04：规模与超预算

输入配置和结果分开保存；公开合成配置／汇总，原始自然数据留在忽略目录。

| 维度 | 至少记录的指标 |
| --- | --- |
| 工作集 | 聊天数、rollout 行数／字节、活跃流数、事件速率、最大输出、迟到和重连比例 |
| CPU／时延 | 事件排队／处理、tick、投影／复制／序列化、分词、冷／热查询、GUI 解码／分组／应用的 p50/p95/p99 和最大值 |
| 后台边界 | HistoryRefresh 请求／结果／每次 drain 字节，超大摘要无 revision；分词请求超限不启动 native worker，native panic／超时／pipe 阻塞／进程退出／关闭后可恢复 |
| 内存 | Python／Swift 峰值与稳定 RSS、索引条目／字节、Future 持有文本、发送队列、所选详情和投影缓存 |
| I/O | 恢复存档次数／字节／耗时、JSONL 扫描／引用读取、元数据增长和故障恢复 |
| 持续运行 | 持续时长、稳定段与增长趋势、活动结束后的资源回落、已知运行边界 |

对每个实际落实的预算都要强制触发上限，再验证降级。尤其覆盖旧 terminal 身份回收后晚到同 ID、旧 backend 重放、过时 tokenizer Future 完成、缓存淘汰后重新查询、上限附近连续重连。

受控压力运行与自然持续运行分别报告。预算值、平台和支持规模在测量后写入 `resource-budgets.md`；未取得数据前不承诺固定 RSS、长时间无泄漏或任意规模支持。

### 组合压力配置

当前已执行配置使用独立 Preview／collector／bridge：50 个合成 session，每源 1,000 个历史 phase，50 个当前流合计目标 1,000 delta/s；两个查询读端轮转读取历史时间线和当前单项详情。每 5 s 追加一个源记录，存档首次写入阻塞 30 s，另一个只读状态端暂停 60 s。运行 300 s 事件负载后停止当前活动，观察 120 s 空闲回落；实际结果与仪器化边界见[实施记录](implementation-results.md#p5组合原生负载与空闲回落)。

记录实际事件数／调度迟到、原始转发摘要、查询冷／热／失败、状态序号与健康、最后结束到 AppKit draw、Python／Swift 及所属计数子进程的 RSS 时间序列、各预算诊断。源文件和所有运行痕迹只留在临时目录或 `.local`；公开 JSON 只保留合成配置与统计。这个受控持续样本不替代自然使用，也不据此声明无泄漏。若当前平台无法完成该配置，保留失败与归因，不通过放宽时延或隐去样本取得通过。

## EH05／EH06：契约、结构与投影

- Python 解析／Swift 解码共用合成 wire 样本，覆盖缺字段、未知枚举、版本、单位、scope 与持久化 allowlist；测试有行为含义，避免只镜像类型字段。
- 领域状态在拥有线程修改，跨线程值不可变；检查 provider／book 锁序及取消任务没有共享可变别名。
- GUI 分组覆盖跨 home 同 thread ID、冲突／循环父关系、隐藏祖先、未知父身份、临时会话和终止后仍工作的真实子智能体。
- 同一状态的多个 getter／行共享投影；统计构建次数和规模变化趋势。排序成本与图遍历分别计量，缓存本身纳入内存预算。
- 新状态抢先到达、旧投影晚完成、语言切换、recent 到期和连接陈旧分别使正确的展示更新，选择、滚动及独立查看器保持。
- 测量前后主 actor 时间与原生 draw；模型规则正确不等同于原生交互性能已通过。

单纯修改本计划时只需检查文档链接、结构／编号和示例格式；实际产品改动按对应阶段执行验证，并把证据追加到实施记录。文档检查不计作产品工程验收。
