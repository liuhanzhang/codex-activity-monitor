## 2. 固定比例与宽度标定

### 2.1 比例定义

令：

- `W_ref`：当前默认展开面板、只有主智能体时，右侧时间线的实际视口宽度，单位 pt，不包含名称区。
- `P`：时间线左右余量之和，现行为 8 pt；不把余量算成可显示时间。
- `Z`：参考档位秒数，取 30、60、120。
- `q = (W_ref − P) / Z`：该档位固定的 pt/s。
- `W`：当前时间线视口宽度，`S = (W − P) / q` 为当前实际可见秒数。

先在隔离原生预览中实测当前默认 420 pt 面板的 `W_ref`，再固化为共用参考常量。当前代码的 291 pt 是旧参考值，尚未证明与当前紧凑面板一致，不能直接把它称作“当前面板宽度”。实施结果必须记录测量值、余量和最终三档 pt/s。

`W_ref` 不在每次开窗、拖宽、出现子智能体或切换聊天时重新采样。同一档的 pt/s 在同一 GUI 版本内保持固定。多智能体名称区较宽导致 `W` 减小，属于实际可见范围变化，不能为凑满 60 秒自动改变比例。

例如默认参考视口显示 60 秒时，若有效绘图区宽度增加为两倍，可见时间也变为 120 秒。这里的“两倍”指扣除余量后的宽度。

### 2.2 控件

- 从默认 60 秒档开始，减号依次到 120 秒，加号依次到 30 秒；中间档两个按钮均可操作。
- 文案显示 `S` 的合理取整值，计算分页始终使用未取整的 `S`。宽度变化后显示 53 秒等数值是正常结果。
- Help、辅助功能值和旧版头部文案一起更新，不能仍声称只支持 30／60 秒。
- 新建时间线 store 默认 60 秒，同一聊天已有的用户缩放选择继续按现有 GUI 会话缓存规则保留；不新增跨重启持久化设置。

## 3. 分段跟随算法

### 3.1 区间与边界

保留比例 `r = 0.25`，每次向前推进 `D = (1 − r) × S`。`T0` 是所选轮次的可靠时间原点，`t` 是跟随时刻相对 `T0` 的秒数。第 `k` 页显示：

```text
[T0 + k × D, T0 + k × D + S]

k = 0                          当 t ≤ S
k = ceil((t − S) / D)           当 t > S
```

正常刷新保留当前页，只有 `t` 严格超过右边界才推进。60 秒整仍在第一页，105 秒整仍在第二页。浮点误差使用很小的时间容差处理，不允许用像素级大容差吞掉有意义的末尾活动。

运行轮次从 bundle 已有可靠时钟取得跟随时刻，不能使用“最后一条活动的结束时间”代替当前运行时间，否则等待期间会停止推进。轮次已明确结束时，只处理最终可靠结束位置并冻结，不按机器当前时间无限翻页。源时钟不可靠或时间原点缺失时沿用现有降级，不另行猜测时间。

长时间隐藏、休眠或轮询跨过多页后，直接算出当前应显示页，只定位一次，不补播中间每一页。相同身份、比例和视口下，不因相同响应重复翻页，也不因轻微时间回退自动向后翻页。

### 3.2 未来区域与历史

分页后，最新活动一般位于视窗左侧约 1/4 处。右边空白有明确含义：它是当前固定区间中尚未发生的时间，不代表缺失历史。

保持现有全历史来源坐标，不为翻页重写 `origin_ms`，不把每一页的刻度重新归零。现有 `60s → 1:00` 等时间格式可继续使用。主、子智能体共用一个页起点和同一横向偏移。

`NSScrollView` 的文档宽度必须至少覆盖当前区间的右边界及边距，同时保留已有历史宽度。否则系统会把合法分页位置钳回已发生历史的末端，重新产生连续跟随。未来区域只影响画布容量，不写入 bundle、活动结束时间或详情耗时。

历史持续可回看。活动跨越窗口边缘时按实际来源矩形绘制并自然裁切，不能为填满可见区域延长活动；短活动的最小可视宽度继续只是命中／显示规则。

## 4. 状态转换与工程默认规则

| 触发 | 视窗与跟随行为 |
| --- | --- |
| 首次显示当前运行轮次／“回到最新” | 保持现有轮次选择语义，直接进入当前应显示区间；不从第 0 页播放到现在。 |
| 同页数据刷新 | 页起点不变，只更新活动、状态与必要画布内容，不启动平移动画。 |
| 超过区间右边界 | 推进到目标页，普通相邻翻页使用短动画。 |
| 手动横向滚动、拖滚动条、键盘／辅助功能导航、点击活动 | 取消动画，在实际可见位置暂停跟随；后续刷新保留阅读上下文。 |
| 阅读状态下滚到末尾 | 不自动恢复跟随；仍通过“回到最新”显式恢复。 |
| 跟随状态切换 30／60／120 档 | 保持当前轮次，按新比例及实际宽度重新计算最新所在页，直接定位；不同时叠加缩放与翻页动画。 |
| 回看状态切换档位 | 沿用现有有效选中活动优先、否则视窗中心时刻的缩放锚点规则；不恢复跟随。 |
| 跟随状态调整窗口宽度／名称区宽度变化 | pt/s 不变，使用新 `S` 一次重算当前页；连续 resize 不播翻页动画，不能每帧追历史末尾。 |
| 回看状态调整宽度 | 保持左侧来源时刻，必要时允许右侧留白；不因内容可全部容纳而跳回起点。 |
| 切换聊天／轮次、响应身份变化 | 取消旧动画和旧分页状态；新响应通过既有请求代次及完整身份检查后再呈现。历史轮次保留现有从起点查看的行为。 |
| 关闭／重开面板 | 关闭时取消动画；重开沿用既有运行轮次恢复最新规则，并直接定位目标页。 |
| 当前轮次结束 | 最终位置必要时定位一次，随后保持视窗，不自动缩小或移到内容末端。 |

窗口变更导致 `S` 改变属于一次明确重算，不把旧页号套到新跨度。原点若因来源补齐而变化，先维护来源时间阅读锚点，并在有效数据上重新计算；不能把数据校准位移误判为用户滚动或普通跨页动画。

## 5. 动画与事件区分

- 普通相邻区间切换采用约 180 ms 的 ease-out 平移，时间轴、条带、选区和可见命中几何保持一致。
- 只改变视窗偏移，不插值活动真实起止或比例，不使用整体视图过渡伪造条带耗时。
- 首次加载、重开、回到最新、跨多页补齐、缩放和 resize 直接定位；它们不是正常的相邻页前进。
- 响应系统“减少动态效果”，启用时直接定位。180 ms 是初始参数，最终观感由原生验证记录。
- 用户介入、视图销毁、轮次切换或几何变化时立即取消动画，以当前实际可见偏移作为后续阅读位置；完成回调不能再次把视图拉回旧目标。
- 现有 `updating` 只覆盖同步更新，不能直接当作跨帧动画期间的唯一保护。动画驱动的 bounds 通知应有明确来源／代次，避免被误识别为手动滚动；同时不能屏蔽真实用户输入。
- 动画只在短暂切换期间驱动必要帧，不为静止时间线增加永久高频刷新。

优先试验 AppKit 原生 clip-view bounds 动画是否能满足中断、重绘和命中一致性。若不满足，再实现局部、可取消的短时偏移插值；API 选择是实施验证项，不能仅凭设置动画时长就宣称已实现正确。

## 6. 组件边界

建议将分页计算提取为 `MonitorModel` 中不依赖视图的纯值逻辑；三档固定比例仍由统一缩放模型提供。`TimelineStore` 保留轮次、缩放、阅读与显式跟随意图，分页的实际宽度、页面位置和动画代次由对应 surface／coordinator 管理。

面板显式传入分段策略，独立活动查看器保持既有横向策略。两处可能共享 `TimelineStore`，不能把某个窗口的宽度、页号或未来画布范围写入另一窗口的布局状态，也不能把两种跟随策略都实现为 `offset = maximum`。共享的选择／暂停跟随行为沿用已有语义。

原生覆盖式滚动条配置保留。内容长度变化仍可能改变滑块长度，悬停可改变粗细；两者不作为本轮缺陷自动修复。仅当观察到与交互无关的闪烁、轨道遮挡或视窗偏移异常，才记录可复现条件并处理本轮引入的问题。
