# 时间线：固定比例与分段跟随

日期：2026-10-22。状态：实现、定向验证、原生预览及有限真实运行核对完成；日常 App 已构建并在用户要求后重载，采集已恢复。详见[实施结果](implementation-results.md)。

源码核对基线：`8df0119`，编写前工作区干净。实施前仍需重新检查源码和工作区状态。

## 目标

运行中的时间线不再每次刷新都追到历史末端，而是在一个固定时间区间内增长；超过区间右边界后，一次向前切换，并保留上一屏最后 25% 的时间上下文。

缩放提供 30／60／120 秒三个参考档，默认 60 秒。参考的是当前默认展开面板的绘图区宽度。选定档位后，单位宽度对应的时间保持不变，窗口变宽／变窄只改变可见跨度。

例如，实际可见跨度为 60 秒时：

```text
运行时间 ≤ 60 秒       显示 0～60 秒
60 秒 < 运行时间 ≤ 105 秒  显示 45～105 秒
105 秒 < 运行时间 ≤ 150 秒 显示 90～150 秒
```

切换后左侧约 1/4 是刚发生的历史，右侧约 3/4 留给后续活动。旧记录不删除，手动横向滚动仍可回看。

## 已确认的决定

| 编号 | 决定 |
| --- | --- |
| D01 | 30／60／120 秒是参考宽度下的三档固定时间比例，默认 60 秒；不是任何窗口宽度下都强制显示这些秒数。 |
| D02 | 沿用原生减号／范围值／加号。减号依次扩大范围，放大则反向切换，档位边界禁用对应按钮。范围值显示实际可见秒数。 |
| D03 | 跟随期间区间内视窗保持不动；严格超过右边界才切换，保留上一屏最后 25% 的时间范围。 |
| D04 | 仅切换区间时做约 180 毫秒、平滑减速的短平移动画，不加弹簧或回弹。普通数据刷新不平移时间轴。 |
| D05 | 手动回看、键盘选择或打开活动详情时暂停跟随；“回到最新”恢复并定位到最新所在区间。 |
| D06 | 跟随状态切换缩放档后定位到最新所在区间；回看状态切换缩放档时尽量保留阅读锚点。 |
| D07 | 活动保持来源时间、身份、真实耗时与质量语义；跨区间活动只按可见区域裁切，详情仍展示完整的可用来源记录。 |
| D08 | 保留原生覆盖式滚动条、自动隐藏和悬停展开行为，本轮不换自定义滚动条。 |

## 范围与既有规则

本轮主要对象是展开面板的 `.panelCompact` 时间线。三档比例属于共用缩放模型；分段跟随策略按展示位置显式启用。独立活动查看器继续保留其现有布局、详情内容跟随和连续横向跟随方式，不因修改共享组件而意外获得面板分页行为。

本章替代第 09／13 章中的“默认 30 秒、仅两档缩放”和展开面板“持续跟到最右端”的规则。[固定比例原则](../09_activity_timeline/fixed-scale.md)、[来源时间与短活动规则](../09_activity_timeline/true-time-tools.md)、[紧凑主子双轨及原生浮层](../13_expanded_panel_round3/README.md)继续有效。

本轮不修改历史读取／存储、活动归属、采集协议、轮询频率、用量计算、菜单栏动画或独立详情正文。第 14 章的[JSONL 活动校准](../14_jsonl_activity_reconciliation/README.md)保持独立。

需求已无需要用户补充的阻塞项。参考宽度的原生实测、动画 API 的可行性及最终观感属于实施验证任务，不能在本章中预先标为已验证。
