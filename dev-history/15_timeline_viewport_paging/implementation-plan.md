# 实施计划

日期：2026-10-22。状态：P0–P4 已完成，实现、检查与加载边界见[实施结果](implementation-results.md)。下文保留实施步骤与退出条件。

## P0：基线和参考宽度

1. 重新检查 Git 状态、当前源码及运行 App 身份，保留其他工作。
2. 复用现有隔离原生 preview／合成 fixture，测量默认 420 pt 面板、仅主智能体时的实际时间线视口及左右余量。
3. 固定共用 `W_ref`，推导三档 pt/s；验证子智能体名称区和宽窗口只改变可见范围，不重新标定比例。
4. 小范围验证 clip-view 动画的可取消性、bounds 通知和绘制；确定原生动画或局部短时插值方案。

退出条件：参考宽度与动画路径有实测记录。测量不读取真实输入内容，不更改采集器配置。

## P1：缩放与分页模型

主要落点：`MonitorModel/Timeline.swift`、`MonitorApp/TimelineStore.swift`、`MonitorApp/TimelinePanelView.swift` 及相关本地化。

- 三档缩放、默认 60 秒、逐级加减、端点禁用、真实范围值与 Help／辅助功能文案。
- 提取区间计算，覆盖严格边界、25% 保留比例、跨多页定位和无效几何。
- 明确所有隐式默认比例入口；避免 store 默认 60 秒而独立布局入口仍偷偷使用 30 秒。
- 将旧“跟随最右端”测试按 presentation 拆开：面板验收分页，独立查看器保留原策略；不删除固定比例和阅读锚点契约。

退出条件：纯计算和缩放定向检查通过，模型不依赖真实时钟推进或长时间 sleep。

## P2：视窗、画布与交互

主要落点：`MonitorApp/TimelineSurface.swift`、`TimelinePanelView.swift` 与必要的 store 状态。

- 显式区分面板分段跟随和独立查看器原策略。
- 以实际视口宽度计算页面，将画布容量扩展到页面右边界；保留来源时间坐标和可回看的全历史。
- 同页刷新不改变偏移，跨页／重开／休眠恢复按规则定位；完成后冻结。
- 保留手动回看、活动选择、键盘／辅助功能导航、缩放与 resize 的阅读锚点。
- 页面状态按 surface 和聊天／轮次身份隔离，避免共享 store 的两个窗口互相覆盖几何。

退出条件：不带动画时所有分页和阅读状态正确；无持续吸附末尾，无裁切导致的时间／身份改变。

## P3：短平移动画

- 仅普通相邻翻页动画约 180 ms，ease-out，无回弹；系统减少动态效果时直接定位。
- 区分程序动画与真实用户滚动。中断后保留当前可见位置，旧完成回调按代次失效。
- 关闭、切换、缩放、resize 时取消动画；静止时不保留高频驱动任务。
- 实际偏移、绘制、点击与辅助功能坐标一致。

退出条件：正常翻页和用户中断均通过原生观察；不能只以最终落点正确替代过程验证。
