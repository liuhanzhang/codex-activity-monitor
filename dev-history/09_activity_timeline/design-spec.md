# 活动时间线：交互与视觉设计

日期：2026-10-19。最新工具规则以[来源时间方案](true-time-tools.md)为准。状态：交互结构及本轮调整已实现，当前原生合成截图见[固定比例对照](fixed-scale.md#原生对照)，此前截图分别见[叠放布局](overlap-layout.md#原生截图)、[后续调整结果](refinement-results.md)及[实施结果](implementation-results.md)。本文线框用于解释结构，参数已回写当前实现。

原始参数／结果和 compaction 规则见[上一轮改动点](refinement-changes.md)；最新布局见[重叠展开与固定范围](overlap-layout.md)。先前顺延排布已改为叠放／覆盖展开，截图分别保留所属轮次的证据含义。

## 1. 视觉基线

延续[现有原生面板](../08_gui_ui_ux_redesign/assets/native-panel-preview.jpg)的系统材质、420 pt 左右宽度、两行聊天、细分隔线和紧凑字号。保留当前动作与速度作为主信息，时间线在聊天展开后出现。

时间线用于感知工作节奏，不在小面板铺开代码、命令、长标签或协议字段。空白代表没有对应类别的已知活动，不用装饰色块填满。菜单栏三点、锤子、沙滩及刷新机制沿用既有实现。

## 2. 面板结构

```text
┌────────────────────────────────────────────┐
│ 已连接                         48 T/s  ⚙  │
├────────────────────────────────────────────┤
│ ▾ 项目介绍与代码行数统计          48 T/s   │
│   codex_progress_monitor · 正在读取   3s   │
│                                            │
│   Output 12.4k        Reasoning 8.2k        │
│   推理均速 42 T/s · 模型名称               │
│                                            │
│   [当前轮 ▾]  用户输入 ↗        每屏 60 秒 │
│           0s         10s         20s       │
│   模型    ░░░ ▒▒  ▓▓▓      ▒▒▒            │
│   工具           █████  ██                 │
│                       ◆ 中途输入          │
│   ▸ 子智能体 · 审查      ▰▰▰▰▰▰           │
│   ▸ 子智能体 · 搜索        ▰▰▰▰▰▰         │
│           ───── 横向滚动 ─────             │
│   思考 · 正文 · 参数 · 编辑      回到最新   │
├────────────────────────────────────────────┤
│ ▸ 另一个活跃聊天                    —     │
│   project · 思考中                   8s   │
├────────────────────────────────────────────┤
│ ▸ 最近完成（2）                            │
│ 2 个活动聊天                               │
└────────────────────────────────────────────┘
```

- 图中的位置、数量和内容仅用于说明结构；不表示同一智能体必须按此串行，也不是任务完成百分比。
- 保留本轮用量、最近推理均速等已有信息。切换到历史轮时不能让“当前轮用量”看起来属于所选旧轮：只有能按真实 turn 读取的指标才随选择切换，否则明确标为“当前轮”，与历史轨迹分隔。
- 初次展开选当前轮；用户选了历史轮后，新轮到来不强制切回，以轻量“当前轮有新活动”入口提示。
- 轮次选择列出当前与最近 5 轮，附时间与状态，不把 steering 列为新轮。初始用户输入入口打开同一个查看器，定位该输入记录。
- 当该轮没有可恢复的轨迹时，显示“这轮暂无可用轨迹／部分记录不可恢复”，不画空轨伪装成完整零活动。

面板按内容向下增长，超过可用高度后列表纵向滚动；时间线自身横向滚动。轨道标签固定在左侧，时间轴、时间块、输入标记与子智能体内容一起水平移动。纵向滚动用于浏览聊天或已展开子智能体，不能代替横向时间导航。

## 3. 固定轨道与配色

| 类别 | 轨道 | 视觉方向 | 文字表达 |
| --- | --- | --- | --- |
| 思考／可见思考摘要 | 模型 | 紫色，浅／深 `#8968B3 / #9A80C0` | 思考 |
| 正文／计划输出 | 模型 | 紫色，`#7957AC / #B097D1` | 正文 |
| 工具参数／代码生成 | 模型 | 紫色，`#6A429E / #C3A2E1` | 参数 |
| 可识别的文件编辑内容生成 | 模型 | 紫色，`#4F2B77 / #DCBAF1` | 编辑内容 |
| 实际工具执行 | 工具 | 暖橙，`#B17130 / #D49B57` | 工具名／执行 |
| 上下文整理 | 模型 | 青灰，`#567D85 / #82ACB4` | 整理上下文 |
| 子智能体折叠汇总 | 子智能体汇总 | 中性色底，保留模型／工具活动的细色段 | 子智能体名称及活动状态 |
| 同轮后续用户消息 | 时间轴附近 | 中性菱形 | 用户输入 |

上表是当前浅／深色 token，基础色块对比度已有自动检查；未知时间和不确定状态另以低透明度及文字提示降级。图例可以紧凑展示，悬停与键盘选择都提供完整类别名称。失败用边框／符号加文字表示，不把全部类别改为红色而失去原分类。

模型与工具轨在当前智能体视图中固定保留，即使其中一条暂时为空。文件编辑生成与普通参数生成之间的区别是静态类型提示；随着输入补齐，若识别证据变得明确，可更新同一块的子类型与颜色，不改变身份或生成时间。

一个 Code Mode 调用含有多类步骤时，如果无法可靠分出生成边界，保留一个参数生成块，并在详情中解释识别到的内容；不把同一段生成时间复制成多个“精确编辑”区间。

## 4. 时间轴与重叠

### 4.1 来源时间与工具近似坐标

`x = (活动时间 − 所选轮次的时间原点) × 缩放比例`。

取消手动缩放按钮，比例固定为 `(291−8)/60 pt/s`。菜单一屏最多 60 秒；详情与调整窗口大小都沿用该比例，只改变可见时长。短轮次留空不拉伸，长轮次横向滚动。刻度间距保持相同，使用相对秒／分，悬停与查看器显示绝对本地时间和来源。最新规则见[固定时间比例](fixed-scale.md)。

- 不为长块设置独立最大宽度，不对每个块分别使用非线性映射。
- 模型短活动视觉最小 1 pt，命中范围独立扩大到至少 12 pt；工具短活动使用 3 pt 粗竖线，命中区等于可见矩形，不移动来源起点或后续活动。工具轨标“工具”，悬停说明粗线及点击查看详情。
- 已完成零时长事件是时间点；缺少起点的活动是“起点未知”，两者不能混用。
- 将来若确需压缩超长空档，只能使用各轨共同的折叠时间区间，并明确画出断轴；首版不实施。

### 4.2 固定高度内表达重叠

每条轨道固定一个槽位，不因为活动数量临时改变高度。工具按来源矩形各自绘制，同色透明度合成只强调当前位置的遮挡，并自然饱和；不画阴影、数量徽标或整组边框，不把间接重叠串成组。浅色工具基色略深，以保持叠色后单层可辨。

点击实际图形直接打开详情：工具命中多项时，将这些工具按开始时间传入同一查看器；点击单项只查看单项。模型阶段继续独立。详情选中成员在点击后固定，刷新仅更新各成员的状态和内容。取消时间线内横向展开及其关闭／Esc 特殊处理。工具可通过键盘和 AX 独立访问。

### 4.3 实时跟随与位置稳定

首次打开当前轮定位到最新活动，菜单最多显示一分钟。接近最右端时可以跟随；用户横向滚动、选择旧活动或切换旧轮后暂停跟随。“回到最新”恢复当前轮与最新位置。

刷新只更新来源几何及状态；工具增长不推动后续条。历史补全保留阅读锚；窗口变宽／变窄不改变比例，阅读历史时保留左侧时刻，跟随最新时保留右端。必要时在右侧留白，避免窗口变宽把阅读位置挤回起点。展开状态按成员稳定身份保留，切轮或成员移除时清理。

## 5. 子智能体

```text
                0s       10s       20s       30s
主智能体  模型  ░░░ ▓▓       ▒▒▒
          工具       ████              ██
▾ 子智能体 · 审查
          模型         ░░░░    ▒▒▒
          工具              █████
▸ 子智能体 · 搜索         ▰▰▰▰▰▰▰▰▰
```

折叠汇总展示该智能体明确关联活动在共同时间轴上的占用片段；真正的空档保留，不用从首次出现到最后出现的一条满块假装持续工作。重叠可以近似合并，用户展开或点击后能访问原始活动。

子智能体由用户主动展开，之后在当前视图保持展开。主智能体并发增加不会改变它的行高。多个子智能体排序按稳定创建／首次确认顺序。多层子智能体使用有限缩进；深层关系和完整归属在查看器说明，不能无限挤窄绘图区。

父轮视图只纳入有明确派发／交互关系的子智能体活动及其来源引用，不把同一 child 的全部历史直接归给当前父轮。无法确定关联范围时，只显示可确认的身份与状态，并说明轨迹未完整关联。

旧轮工作仍运行时，该旧轮范围可延伸到其活动的实际终点；父轮“完成”仍是独立时间点，不延迟或改写父轮状态。新轮显示“前轮仍有活动”入口，点击切回相应旧轮。

## 6. 独立活动查看器

采用普通 `NSWindow`，起点约 800×600 pt，建议最小约 640×420 pt；最终根据原生窗口与可访问字号验证。位置和大小记忆后应按当前显示器可用区域校正。使用标准标题栏和窗口按钮，可拖动、缩放、最小化，普通窗口层级。

```text
┌─ ● ● ●  活动查看器 ───────────────────────────────┐
│ 项目介绍与代码行数统计  ›  第 3 轮  ›  子智能体审查 │
│ 工具执行 · 读取文件      已完成 · 16:24:33 · 1.2s  │
├───────────────────────────────────────────────────┤
│ 模型  ░░ ▓▓▓      ▒▒▒        该轮共同时间轴       │
│ 工具        █████ [██]                              │
├───────────────────────────────────────────────────┤
│ 概述   输入   输出                       复制      │
│                                                   │
│  按内容类型呈现完整可用文本／代码／JSON／diff        │
│  内容很长时渐进加载和虚拟化，可继续读取保留的全文    │
│                                                   │
│  仅在实际存在时说明：来源截断／部分观测／尚未落盘    │
└───────────────────────────────────────────────────┘
```

正文仍按自身类型阅读；工具及参数生成活动统一“参数／结果”。字符串不二次解码重排，对象／数组保留结构，文件修改展示原始 changes／status，不拼装差异视图。缺字段在对应区域说明，空字符串与 null 等合法值单独表达；分块读取不伪装成完整结果。

窗口顶部保留紧凑同轮时间线及智能体归属切换。对很多子智能体，默认定位所选智能体，允许展开相关轨道，不强迫一次铺开全部行。多项工具直接在详情中纵向展示，每项独立的参数／结果、耗时、加载及分页状态；内容区独立滚动，工具间可纵向滚动。小于一秒的详情耗时显示毫秒。

### 打开、刷新与关闭

1. 点击时间块先确定稳定选择，再收起 popover，并打开或前置现有查看器；加载期间保留所选上下文与占位状态。
2. 后续从面板点击其他活动，复用窗口并切换到该活动；仅后台新事件到来不会切换。
3. 查看器自己的实时更新不拉回焦点。内容在底部且用户选择跟随时才自动跟随新增内容。
4. `Cmd+W` 关闭窗口；`Esc` 优先收起重叠展开条，不把长文本阅读器做成失焦消失的 popover。
5. 关闭窗口释放专用内容加载与临时缓冲；菜单栏及观察会话继续运行。退出 App 仍按既有流程停止观察。

普通可持续阅读的窗口符合本场景，也与 Apple 的[窗口](https://developer.apple.com/design/human-interface-guidelines/windows)和[临时 popover](https://developer.apple.com/design/human-interface-guidelines/popovers)定位一致。本机 accessory App 的窗口前置、复用、关闭与继续采集已有针对性原生检查；全场景和发行范围见实施结果。

## 7. 异常与可访问状态

| 情况 | 表达 |
| --- | --- |
| 仅拿到完成事件，起点不可恢复 | 终点标记或缺口样式；耗时 `—`，保留可用内容 |
| 观察中断／重启 | 质量提示；活动不再无限增长为可信“进行中” |
| 等待审批／输入 | 不单独画点，保留既有当前状态；不复制操作按钮 |
| 历史尚未写完 | “完整内容尚未写入历史”，可更新／重试 |
| 历史被删除或无法访问 | 保留已知元数据，说明内容不可用；不删除仍可解释的时间块 |
| 来源截断 | “来源已截断”，展示现有内容，不承诺找回丢弃部分 |
| 密集重叠 | 数量与层叠边缘；可用鼠标／键盘横向展开成员 |
| 没有可恢复轨迹 | 区分暂无事件与该历史格式不含所需时间 |

轨道、活动和输入标记提供有序的可访问元素，读出类型、所属智能体、状态和时间；键盘可逐项访问并打开。大量事件可分页或分组导航，不能创建无法退出的巨大焦点序列。颜色之外使用图例、文字和形状；减少动态效果时只做离散更新，不做强调脉冲或自动平移动画。
