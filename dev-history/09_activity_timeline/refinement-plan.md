日期：2026-10-17。状态：Q0–Q4 已完成本轮实施与针对性验收，日常 Monitor 已载入新代码。已确认的目标与边界见[后续改动点](refinement-changes.md)，实际执行、证据层次和未验证范围见[本轮结果](refinement-results.md)。

当前工作区已有首轮时间线的暂存变更。实施前记录工作区与暂存区状态，只修改本轮明确涉及的文件，不清理、重置、提交或推送其他工作。

| 阶段 | 内容 | 主要文件 |
| --- | --- | --- |
| Q0 | 核对来源契约，固定最小合成样本及验收编号 | `history.py`、`timeline.py`，既有测试及 `experiments/timeline/` |
| Q1 | 过滤非输入 marker，将 compaction 投影为模型过程 | `timeline.py`、`timeline_query.py`、必要的 `history.py` 与 Swift 类型／图例 |

## 2. Q0：确认来源和基线

1. 对照当前源码和既有来源记录，核对 canonical 工具字段、raw `arguments / input / output`、compaction 边界及无正文类型。
2. 用已有小型夹具补齐本轮真正缺少的场景：旧 hook 侧文件、compaction 实时与历史合流、密集短工具、原始结构化返回、字段缺失及明确来源截断。只使用手写合成内容。
3. 核对内部工具的时间质量。部分边界可能仅代表来源生命周期，缺失或异常区间不能借最小宽度伪装为准确耗时；此阶段不另建外层计时兜底。
4. 固定源字段映射及可用性表达，确认必要 DTO 变化是否能以可选字段兼容旧客户端。若必须升级契约，明确版本与降级路径。

**退出条件**：字段映射有源码／夹具依据；本轮不依赖尚未取得的外层执行边界、推测性父子调用关系或完整问答历史。

## 3. Q1：收敛可见活动

1. 在查询／展示合流处统一规定可见类别，让新实时记录、历史记录及旧侧文件得到相同展示。普通 marker 只保留用户消息。
2. 保留 canonical 用户消息的稳定身份、首条输入入口与同轮后续输入点。失败 steering 和提问请求结束不产生额外用户输入。
3. 将 canonical `contextCompaction` 映射到模型轨；保留原阶段身份和有效起止来源，合并实时与历史，不重复画旧完成通知。
4. 隐藏项同步退出鼠标候选、键盘顺序、可访问元素及查看器导航；观察缺口继续由质量信息表达。
5. 给上下文整理补充名称、样式与图例；只有过程元数据时显示说明，避免进入错误的“历史已移除”状态。

**退出条件**：普通菱形只代表后续用户消息；compaction 是可选择的过程条；保留内部命令／MCP／文件活动；旧侧文件不会让隐藏 marker 重新出现。

## 4. Q2：统一原始详情

1. 保留 `RolloutIndex` 的身份校验、offset 索引和 `call_id` 配对，按[字段映射](refinement-changes.md#41-原始字段映射)读取源值。
2. 工具内容区统一命名为“参数”“结果”。直接渲染原值，移除工具专用的 diff 组装、字符串 JSON 二次解析及结果数组展平；不修改源文件。
3. canonical 工具缺少独立参数时仅在参数区说明缺失，结果区仍展示来源记录。无法通用拆分的工具保留原始 item JSON，不能解析外层代码来填内部参数。
4. 区分字段缺失与合法空值；明确“此类型无正文”“暂未落盘”“未保存”“读失败”“源文件已移除”，纠正笼统的 missing 文案。
5. 保留单次分块预算、继续加载与复制行为。来源截断和分页分别表达，明确截断标记只在适用的结果来源中识别。
6. 复用单查看器、后台读取、取消及迟到响应保护。原始参数／结果不进入 snapshot 或元数据 SQLite。

**退出条件**：内层工具和模型参数生成活动都能查看自己来源中的原值；内容不被错误拼配、重写或静默截断；缺少正文的合法过程不再提示文件已删除。

## 5. Q3：实现近似工具布局

1. 为所选轮次／当前可视轨道建立按阶段 ID 索引的布局结果；模型过程与输入点继续采用原时间坐标，工具采用最小宽度及顺延规则。
2. 每条工具轨独立按时间锚和稳定 ID 排序。最小宽 12 pt、间距 3 pt 集中定义；本轮原生预览后保留这组数值。
3. 将实际绘制、鼠标命中、悬停、选择边框、键盘导航、可访问 frame 和滚动到选中项接到同一组矩形。工具命中区不能再次跨过间距，制造新的候选重叠。
4. 扩展画布到顺延后的最右端，保证最后一个活动可滚动到达；保留长过程宽度，不新增独立最大宽度或持续自动缩小。
5. 补充紧凑的工具近似布局说明。正常工具块直接打开详情，保留模型真实重叠、输入点或子智能体汇总的必要消歧。
6. 刷新、活跃条增长、缩放和历史补全时保持阶段身份、相对顺序、选中内容及阅读锚；不把 GUI 偏移写回后端时间。

**退出条件**：密集短工具可逐个直接点击；顺延末端可达；主／子工具轨的几何互不污染；模型及 compaction 位置、来源耗时与回合总耗时不受工具排布影响。
