# 独立设置窗口与运行诊断

日期：2026-10-28。代码基线：`6c39325`。状态：P0–P6 实现与当前环境验收完成，本章随功能一并提交。日常 Monitor 已按后续请求原位更新并重启；macOS 14／15／26 实机、减少透明度及真实 Codex 完整重启未验证，详见实际结果。

本轮将齿轮菜单改为独立设置窗口，把 Codex 接入改成带有生效反馈的开关，并集中呈现 Monitor 的当前异常和诊断日志。主弹出面板只做背景的最小调整，让原生 `NSPopover` 管理系统外观。

## 已确认的决定

- 设置窗口采用左侧导航、右侧页面，页面为「通用」「运行状态」「日志」。
- 通用设置按模块组织，包含应用设置和 Agent 接入；Codex 不单独占一个侧边栏页面。
- 本轮只实现 Codex，后续 Agent 在通用设置中增加接入区域，状态和日志可以按来源区分。
- 首次安装启动继续自动接入；已有安装保留状态，主动关闭后重开 Monitor 仍保持关闭。
- 打开接入开关执行配置，关闭执行恢复；分别显示配置结果、运行结果和重启要求。
- 使用原生容器及控件的系统外观，不为玻璃材质维护两套版本分支。主面板先移除显式 `.regularMaterial` 背景，再通过原生预览确认效果。
- 诊断基于可验证的运行信号；已有心跳、错误和计数可以复用，但需要补充检测、恢复判定、结构化记录及 UI。

## 实施边界

窗口尺寸、日志预算和退避参数属于工程默认值，不作为用户逐项确认过的设计。实际选值、边界测试和与初案的差异见实现结果。

本轮不重写活动、速度或时间线语义，不增加其他 Agent 的实际适配，不自动重启 Codex，不引入新的驻留守护进程或远程日志服务。配置备份、归属比较、观察租约和安全清理沿用现有约束。
