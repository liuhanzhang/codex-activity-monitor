## 阅读与复用

- 页面中的聊天、时间线、用量、状态和耗时全部是示例数据，不读取真实快照、JSONL、数据库或 socket。
- 可切换单聊、三聊、12 聊、子智能体，显示最近完成，切换轮次，查看用户输入，以及用减号／加号切换缩放。
- 聊天列表最多 5 行，超过后仅列表滚动。此页面没有模拟 macOS 的屏幕可用高度，正式 App 需要另做窗口边界处理。
- 页面采用系统字体和灰阶。图例中的“模型／工具”仅示意图例位置；正式 App 保留现有的活动类别、颜色、选中和失败标识，见[设计说明](../design-spec.md)。
- 原生 `Picker`、`Button`／`ControlGroup`、浮层外观、真实活动命中、辅助功能和日常运行效果，不能由此页面代替验收。

## 导出方式与依赖

原始片段来自本次对话的最终 `monitor-wireframe-v5.html`，按 Visualize 的独立导出流程生成 `wireframe.html`。片段中的 `window.openai.widgetState`／`setWidgetState` 在独立页面由导出器提供本地回退；可选 `Tweak` 不存在时不启用，不影响普通交互。

导出器版本：Visualize `1.0.50`。重新导出时，将本目录原始片段传给该 skill 的 `scripts/render.py`，以本目录的 `wireframe.html` 为目标；覆盖已有导出需要加 `--force`。不需要部署或发布。

独立 HTML 仍通过 CDN 加载图标和提示定位组件：`lucide@1.17.0`、`@floating-ui/core@1.7.3`、`@floating-ui/dom@1.7.4`，因此不是完全离线包。这里没有把第三方运行库下载或引入产品依赖。
