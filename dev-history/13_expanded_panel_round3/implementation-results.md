# 第三轮展开面板实施结果

设计日期：2026-10-20。验收更新：2026-10-21。状态：实现、定向回归、关键原生交互及有限来源核对已完成，日常 GUI 已载入。源码起始版本 `768aa6e`；本记录形成于提交前，提交身份及推送状态以 Git 为准。机器可读证据见[验证清单](assets/implementation-validation.json)。

## 1. 交付内容

- 统一聊天列表与唯一选择：默认显示活跃主聊天，最近完成追加到同一列表；稳定排序，结束时保留阅读，重开恢复活跃过滤。已知子任务有归属待确认入口，不混入主聊天数。
- 聊天行高 56 pt，正常最多显示 5 行，不足时缩短窗口；超出后列表独立滚动。列表、所选详情及多成员轨迹共享屏幕高度预算。
- 面板专用 `panelCompact`：主、子成员固定模型／工具双轨，每轨 18 pt；活动保留 11 pt 高、最短 3 pt 宽。名称缩进不改变时间原点，无成员展开按钮或汇总轨道。
- “本轮活动”为原生轮次菜单，输入按钮紧邻标题；右侧是原生加减按钮及只读可见范围。图下保留一份活动分类图例，以及一行输出／含推理／推理均速。
- 原生输入浮层支持原始文本选择、复制、限高滚动、分页和明确的来源状态。关闭、换聊天、换轮次使旧请求失效；Esc 优先关闭子浮层，主面板识别其窗口归属。
- 独立活动查看器、来源时间、原始参数／结果、质量标记与逐字段统计归属继续沿用既有契约。采集代码、协议、指标算法和菜单栏动画未改动。

## 2. 原生标定与修复

`ControlGroup` 在本机将中间范围文字画成禁用按钮，因此最终使用 `HStack` 组合两个原生 bordered `Button` 和只读 `Text`，两侧图标尺寸相同。沿用 30／60 秒参考比例；正常单成员实际可见约 37／74 秒，多成员约 29／58 秒，文字按真实绘图区宽度计算。

成员名称和状态从相邻两条具备完整线程身份的 lane 派生，不额外保存可能漂移的成员几何表。纵向滚动同时移动名称和轨道。

原生检查发现并修复了两处行为：历史轮到达前的旧 bundle 不再提前改写绘图轮次，避免历史活动偏出视口；选择最近完成或归属待确认项不再将其移到同组其他行之前。两处均补充行为回归，并在原生界面复查。

## 5. 有限实际来源核对

现有只读 `timeline-query` 返回 3 个样本：1 成员／170 阶段、3 成员／253 阶段、1 成员／0 阶段。后两者分别保留 `observation_gap` 与 `history_unavailable`。

前两个 bundle 未改写身份、阶段或时间，以冻结样本送入原生 Preview；仅外层只读快照使用明确的“冻结来源样本”名称并刷新文件新鲜度。两个样本当前视口各 10 个活动 ID 均匹配来源，3 个明确成员均出现，部分观测提示保留。没有匹配用量来源时统计为 `—`。

独立查看器中，单成员工具参数前 100 字符、结果前 150 字符与来源一致；明确子任务工具的参数／结果各前 150 字符、所属标签及来源时长也匹配。这是有限样本检查，未逐个验证全部 423 个阶段或整份长正文。原始 JSON、详情、AX 与真实截图只位于 `.local/round3/source-check/`、`.local/round3/source-native/`，不纳入公开材料。
