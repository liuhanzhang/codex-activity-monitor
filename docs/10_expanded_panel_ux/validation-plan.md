# 验收计划

日期：2026-10-19。状态：已按受影响范围执行，逐项证据及未覆盖部分见[实施结果](implementation-results.md)。下表是验收目标，不能单凭此表宣称全部通过。本轮只验收展开面板改动及其既有调用兼容，不新增单聊详情页，不重做独立窗口的 UI/UX 验收。

## 1. 定向验收矩阵

| 编号 | 场景 | 通过条件 | 证据 |
| --- | --- | --- | --- |
| V01 | 首次打开、一个／多个运行聊天 | 运行聊天各自默认展开，本轮时间线先于简要统计，所有内容仍在同一面板。 | 状态测试＋原生操作 |
| V02 | 最近完成 | 新一次展示默认只见分组标题和数量；展开后条目默认收起，点击行为明确。 | 状态测试＋原生操作 |
| V03 | 手动覆盖与刷新 | 手动收起运行聊天、展开最近完成或某条记录后，多次快照刷新不覆盖选择、不按速度重排。 | 状态测试 |
| V04 | 原地展开与活动入口 | 没有单聊详情跳转和返回入口；轮次切换、模型说明在展开区，点时间块打开既有活动窗口。 | 原生操作 |
| V05 | 新聊天、完成与重开 | 新运行聊天默认展开；完成不清空无关选择或关闭既有窗口；重开应用默认分组规则。 | 状态测试＋原生操作 |
| V06 | 聊天、轮次与统计布局 | 轮次选择统领时间线和统计；统计按指定概念图左输出及含推理、右推理均速两列排列，标签在上、主数值在下；历史状态与当前动作不混淆。 | 合成数据＋原生检查 |
| V07 | 统计缺失、迟到及跨轮 | 只有可靠归属的数值进入本轮统计；历史缺失为未知，迟到旧轮用量和旧推理均速不串到新轮。 | 统计投影测试 |
| V08 | 原有时间线回归 | 缩放、默认最新、阅读暂停跟随、3 pt 命中、工具集合、模型独立选择、淡蓝选区和结果图标保持。 | 受影响的既有测试＋少量实际点击 |
| V09 | 状态与时间含义 | 空闲／断连不冒充完成；零和未知不同；动作耗时与整轮耗时不同；最近进展不冒充结束时间。 | 展示投影测试 |
| V10 | 展开与内部控件 | 原生控件方向正确，标题区域可点击；点轮次、缩放等内部控件不顺带折叠聊天。 | 原生鼠标检查 |
| V11 | 键盘、AX 与减少动态效果 | 可聚焦并操作控件，读出名称和展开状态；焦点不因刷新丢失，减少动态效果时无多余展开运动。 | 原生键盘／AX 检查 |
| V12 | 既有窗口调用兼容 | 单项和重叠工具传入正确记录与集合，复用现有窗口；仅回归面板调用路径，不改窗口 UI/UX。 | 有限既有回归＋原生点击 |
| V13 | 长标题、多聊天、子智能体 | 420 pt 起点下不截断关键状态；多个默认展开不溢出屏幕；父已结束而子仍运行的分组正确；无重复轮询。 | 合成预览＋查询诊断 |
| V14 | 外观、锚定与关闭 | 聊天和轮次使用中性分组，浅／深色可读，原生细滚动条；面板在菜单栏下方，外部点击、Esc和设置菜单正常。 | 原生操作 |
| V15 | 管理与加载边界 | 设置、恢复、登录启动、退出及禁用条件保留；展开与活动窗口入口不改变采集所有权。 | 局部回归＋运行元数据 |

## 2. 执行范围

优先对新状态管理和统计归属写有区分力的测试，复用已经有效的时间线回归。原生组件的外观、整行命中、焦点和阅读锚点需要实际操作，不能由静态截图替代。独立窗口本轮只检查面板调用兼容，既有窗口自身的布局与功能验证不重复执行。

实现阶段运行受影响的 Swift 测试和 `bin/build-gui`。Python 投影或协议若没有修改，不重复采集、用量与历史全套检查；若归属核实导致最小字段调整，再增加对应的有限回归。

默认展开会增加可见聊天的时间线查询，需确认同一聊天只存在一套有效轮询、离开可见视图后任务取消，隐藏的最近完成不主动读取全文。不为此调整采集频率或预取全部历史。
