## 3. 对照证据

身份与协作展示会使新的展示字段及可理解 label 变化，不能要求整个新旧 bundle 字节完全一致。对照必须固定相同来源快照和时间，分别验证：

1. 预期变化：名称／来源、组标题、轮次状态、协作展示字段及 revision。
2. 必须相同：scope、thread、turn、phase ID、来源时间、phase track／kind、阶段数量、父轮引用范围、earlier-active 归属和原始内容。
3. 布局影响：水平几何与比例相同；垂直坐标只随明确新增 header／summary 行变化。

性能使用同一机器、同一脱敏工作负载对照首读和少量后续刷新，并记录调用次数；第 09 章曾测得的约 34 ms 后续查询只是旧样本，不作为所有历史与机器的固定 SLA。

截图应覆盖两个外观与三子智能体场景，保存实际原生尺寸及左右标签、轨道、状态和窗口模式。概念稿与 fixture 不是日常运行证据；日常查询正常也不能替代新的交互与布局验收。
