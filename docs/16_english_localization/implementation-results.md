# 英语支持：实施结果

日期：2026-10-22。源码起点：`5b3c0d3`。状态：英语支持已实现，资源、定向检查、隔离构建及原生验收完成；随后按用户要求构建并重载日常 App；本章代码与验收记录纳入本地 Git 提交，未推送。

## 1. 已实现的行为

- 正式发布 `zh-CN / en` 两种资源。默认中文，GUI 设置中选择「简体中文 / English」即时生效；终端支持 `watch --lang en` 和 `l` 切换。没有“跟随系统”选项。
- GUI 自有文案覆盖主面板、状态／覆盖说明、时间线、协作动作、独立 Activity Viewer、输入与活动详情、管理状态、恢复确认、Help 和辅助功能。聊天标题、原始输入、命令、路径、工具结果等来源内容保持原样。
- GUI 偏好在现有数据目录 `app-state.json` 中合并保存；终端仍使用运行目录中的 `ui-settings.json`。两者独立，不增加跨进程同步。快速切换串行保存，以最后一次选择为准；失败保留当前语言并提示未保存。
- 管理操作进行中或等待恢复清理时，语言入口暂不可用。恢复、清理、退出会先等待已发起的语言保存，避免清理后保存进程重新创建数据目录。语言切换本身不配置接入、不启停采集。
- GUI 使用结构化活动消息；Swift 模型格式化显式接收语言，不维护全局可变语言。管理错误保留原 code 和旧正文，新增消息 key／参数，能随界面语言重新渲染；未知错误保留原始诊断。
- 快照、历史查询与详情只增加可选展示元数据；保留旧字段和版本。旧中文标签缺少可确定语义时，英语使用通用状态或活动名，不反向猜译。机器 JSON、原始来源、活动身份、生命周期与指标语义继续沿用原规则。
- 窄面板中，英文图例和“回到最新”等操作不能同排容纳时改为两行，避免词中断行。修正独立查看器子智能体行的 Help／辅助功能使用旧中文标签的问题。

## 4. 实际原生观察

使用只读合成预览实际操作并读取原生辅助功能树，已确认：

1. 默认 420 pt 面板中，单／多活跃聊天显示 `1 active chat / 3 active chats`；中英文菜单切换即时更新当前活动、数量、轨道说明、统计、Help 和窗口标题。选择及阅读中的活动 ID 保留。
2. 输入浮层标题、复制／关闭按钮为英语，中文输入原文不变；独立 Activity Viewer 的类别、状态、Input／Result 页签、复制、来源说明、时间与未知耗时为英语，原始 JSON 保持原样。
3. 未归属入口显示 `Unassigned subtask (1)`，展开后保留实际聊天名称；最近完成入口、单复数和有限列表正常。
4. 部分覆盖显示 `Partial observation`、总速度不可用原因及 `Observed subtotal 48 T/s`；断连显示等待连接说明，源状态不可用时使用保守提示。没有将未知总速度显示为零。
5. 回看后出现“回到最新”时，英文图例完整留在第一行，协作／提示／操作换到下一行；主子轨道保留固定时间比例。
6. 实际英文恢复 sheet 的解释、清理选项、Cancel 和 Restore configuration 文案完整，深色下原生突出按钮可读；只执行取消，没有实际恢复／清理。全新空状态显示 `No active chats`。
7. 用仅影响预览进程的 `-AppleLanguages '(en)'` 启动，未指定语言、无日常偏好时仍显示中文；没有修改系统语言设置。中英文浅／深色布局另通过原生视图检查。
8. 原生测试验证已打开 Viewer 随语言变化更新，文本视图对象、内容、选中文字、滚动位置、所选轮次和缩放／跟随状态保留；不以关闭重开窗口代替刷新。

公开可复用的输入只有合成 fixture 和测试样例，本轮没有提交真实聊天、原始快照或用户输入。

## 语言子菜单自动收起修复

用户报告语言选项来不及选择就消失。日常 App 和持续刷新的只读合成预览均复现：设置主菜单仍在，语言子菜单自行收起。原来的菜单直接位于 `DashboardView` 的计算属性中，面板每秒读取快照会连带更新语言 Picker。将其拆成独立的 `DashboardSettingsMenu`，仅传入语言、操作可用性与登录设置等不可变值，并用相等性比较跳过无关刷新后，相同预览中的子菜单不再被轮询重建。没有暂停采集或改动面板外部点击关闭的规则。

修复后的原生预览中，中英文子菜单均保持展开，成功完成中文 → English → 中文切换，当前语言的勾选和新图例正确。诊断同时确认轮询仍持续运行（12 个 tick 覆盖约 11.67 秒）。语言切换／保存／失败提示／偏好、面板位置及辅助浮层关闭的 7 项已有定向检查通过，资源完整性检查、预览与日常构建通过。自动化期间出现过菜单 AX 操作超时及进程切换后的旧绑定，重新绑定后取得了上述实际交互证据；不将超时本身算作交互成功。
