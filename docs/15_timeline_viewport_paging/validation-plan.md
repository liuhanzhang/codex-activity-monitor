# 验收计划

日期：2026-10-22。状态：本轮定向验收已执行，结果与尚未验证项见[实施结果](implementation-results.md)。本文件继续作为验收标准。

## 1. 缩放与纯计算

| 场景 | 预期 |
| --- | --- |
| 三档与默认 | 新 store 默认 60 秒参考档；30／60／120 逐级切换，两个端点禁用正确。 |
| 比例与尺寸 | 标定宽度下准确对应 30／60／120 秒；有效宽度扩大／缩小时跨度同比变化，同档 pt/s 和同一活动宽度不变。 |
| 名称区变化 | 出现子智能体后实际范围文案改变，但主／子活动同一时刻仍对齐；不重新标定比例。 |
| 60 秒边界 | `0、59.999、60` 秒均在 `0～60`；略大于 60 到 105 秒均在 `45～105`；略大于 105 秒进入 `90～150`。 |
| 30 秒边界 | 第一页 `0～30`，之后 `22.5～52.5`、`45～75`，保留 7.5 秒。 |
| 120 秒边界 | 第一页 `0～120`，之后 `90～210`、`180～300`，保留 30 秒。 |
| 非整数跨度 | 例如实际可见 53 秒，按实际精度计算保留与步长，不使用文案取整值。 |
| 时间跳跃 | 一次跨过多页直接定位当前页，不逐页动画；重复同一时间输入不移动，微小回退不自动向后翻。 |
| 无效输入 | 尚未布局的零宽度、非有限时间、缺失原点等不产生 NaN、无限循环或猜测的分页。 |

边界使用明确输入和小容差断言，不以等待真实 30／60／120 秒作为模型测试方法。

## 2. App 状态与画布

- 同一页内连续更新多个 bundle，视窗左侧来源时刻不变；跨页后最新点位于左侧约 1/4，右侧未来区域可见。
- 画布至少覆盖当前页右边界。AppKit 更新文档尺寸后，页起点不会被钳回历史末端；手动回看旧页仍可访问全部记录。
- 用户滚动、拖动、点击活动、键盘和辅助功能导航均暂停跟随；新数据不能抢回位置，滚到末尾不隐式恢复。
- “回到最新”、首次加载长运行轮次、重开面板以及恢复隐藏状态直接定位目标页，不补播。
- 跟随时切档定位最新所在页；回看时切档保留有效选中活动或中心时刻。resize 保持比例，回看时保持左侧时刻。
- 完成事件后按最终可靠时间处理一次，后续时钟／刷新不会继续翻页；缺失／不可靠时钟保持既有降级。
- 切换聊天／轮次时旧响应、旧页和旧动画不能串入新选择；来源原点补齐时保留语义锚点。
- 面板与独立活动查看器同时存在时，宽度和分页状态互不覆盖；独立查看器保留原有横向及正文跟随规则。
- 长活动跨区间、短工具、输入标记、失败／阻止和重叠活动的点击仍返回原身份；详情耗时不被可见裁切改写。

## 3. 动画与原生观察

使用可控合成时间推进复用现有原生 preview，至少检查：

1. 60 秒档在第一页停留、普通跨页、第二页停留；30／120 秒档分别抽查一次跨页。
2. 正常相邻跨页约 180 ms 平滑减速，无回弹、重复触发、条带拖影或明显跳闪。
3. 动画中手动滚动／拖动，立即接管并停留在实际可见位置；继续刷新和旧动画完成均不会拉回。
4. 动画中点击活动、切换聊天／轮次、关闭面板、切档或 resize，不串身份、不补播旧动画。
5. 系统减少动态效果下直接定位；视窗静止时不持续产生平移动画驱动。
6. 单主智能体、多智能体、宽／窄视口、浅色／深色下，时间轴、条带、选区与命中位置一致。
7. 保留原生滚动条的悬停展开和自动隐藏；观察是否遮挡工具轨道或引起视窗位移，记录触发条件，不把正常粗细变化判为失败。

静态截图只能证明布局和落点，动画节奏与中断行为需要实际操作或短录屏证明。公开材料仅使用合成数据。

## 4. 有限真实运行观察

在构建与隔离预览通过后，用一个实际运行中的聊天观察一次边界前后、一次手动回看和恢复最新。可以利用已有长轮次，不为了测试重新派发业务任务或生成大量工具活动。

确认真实等待阶段仍按可靠时间推进，采集刷新正常，最终活动与详情身份不变。真实输入和原始内容保留在忽略的本机目录，文档只记脱敏结论及必要构建身份。有限观察不能替代长期自然使用或发行验证。

## 5. 检查入口与证据

优先扩展 `TimelineTests`、`TimelineStoreTests`、`PanelUXTests` 和被触及的 `TimelineDecorationTests`；必要时为分页纯计算新增专门测试。不要通过把所有旧断言机械改为“新数值”掩盖阅读锚点回归。

后续示例命令，实施时按实际新增测试名调整：

```sh
swift test --disable-sandbox --cache-path .local/swift-cache --package-path macos \
  --filter 'TimelineTests|TimelineStoreTests|PanelUXTests|TimelineDecorationTests|TimelineViewportTests|TimelineNativeViewportTests'
bin/build-gui --preview
```

需要窗口环境的用例沿用 `MONITOR_WINDOW_TESTS=1` 门控，只运行与本次变更相关的场景。构建、无窗口测试、原生 preview、日常 GUI 已加载和真实运行观察必须分别报告。文档阶段只做文档检查，后续实施阶段已执行定向产品验收；未执行项不能由本计划推定为通过。

本轮窗口测试实际入口：

```sh

  --filter 'unchangedAppKitBounds|externalScroll|TimelineNativeViewportTests'
```
