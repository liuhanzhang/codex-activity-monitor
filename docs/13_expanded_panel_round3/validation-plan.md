# 第三轮展开面板验收计划

日期：2026-10-20。状态：2026-10-21 完成定向回归、关键原生交互与有限来源核对；各项目的证据层次、复用范围及未验证边界见[实施结果](implementation-results.md)。文档与线框导出的静态检查另记在[材料清单](assets/manifest.json)，两者不可混为产品验收。

## 1. 证据与通过规则

优先使用现有只读 fixture 入口与隔离 GUI，补充本轮缺少的合成场景；只运行受影响契约的定向回归。每条结果记录场景、源码／构建身份、动作与观察，不能仅写“肉眼正常”或用旧版本截图替代。

阶段模型与状态测试证明逻辑；原生预览证明当次构建的交互和尺寸；有限实际来源核对证明所检查样本的身份与内容。它们都不自动证明长期自然使用、全新机器安装或公开发行效果。

## 2. 统一列表与选择

| 场景 | 通过标准 |
| --- | --- |
| 1／3／5 个活跃主聊天 | 所有行完整展示；不足 5 行不补白；单选查看区；窗口不超可用屏幕。 |
| 6／12 个活跃主聊天 | 正常屏幕列表最多 5 行，列表独立滚动；可选到最后一行，活动区不被整段列表挤走。 |
| 活跃＋2 个最近记录 | 默认隐藏最近；点击后追加到同一列表、活跃在前、无重复行；不抢已有选择。 |
| 无活跃／无任何聊天 | 紧凑空态；有最近候选才提供入口；活动区不保留空白高度。 |
| 同标题／不同 scope 的聊天 | 独立选择，轨迹和详情不串；主聊天计数只计算确认的主聊天。 |
| 每秒速度／动作刷新及新聊天加入 | 既有稳定顺序、选择与阅读位置不跳变；新行不依瞬时速度插队。 |
| 选中聊天完成／失败／停止 | 本次展示保留一条真实状态行及阅读上下文，不再计活跃；切换离开后按过滤规则隐藏。 |
| 收起最近、关闭后重开 | 收起所选结束项时回到活跃或空态；重开默认隐藏最近，只恢复仍活跃的上次选择。 |
| 来源暂缺或快照过期 | 不把消失推断为成功；旧实时状态降级可见，不无限宣称仍在工作。 |
| 归属待确认的已知子任务 | 明确标记、不猜父关系、不计主聊天数，仍有查看入口且不突破高度预算。 |

同时观察请求：面板只刷新所选聊天；快速切换、隐藏面板后旧任务停止。已打开独立活动窗口的既有刷新不应被误取消。

## 3. 紧凑轨道、几何与活动身份

| 场景 | 通过标准 |
| --- | --- |
| 无子智能体、1／4／12 个成员 | 主、子成员固定模型／工具双轨，无展开箭头和隐藏的折叠命中区；无子时无重复主标题。 |
| 多层明确父子关系、同名成员 | 名称轻度缩进、完整身份稳定；不因同名合并，不无限缩进绘图区。 |
| 同时间锚点的不同成员活动 | x 坐标一致；缩放后仍一致，纵向滚动后名称与条带对应不变。 |
| 极短活动、邻近模型／工具活动 | 最小可见条宽不伪造来源时长；点击身份与实际绘制矩形一致，不串轨。 |
| 同轨重叠活动／协作标记 | 仍按既有选择规则打开正确活动集合，阶段身份与顺序不被紧凑布局改写。 |
| 活跃、失败、被阻止、部分覆盖 | 既有颜色／符号／质量提示可读；灰阶线框不替代正式分类。 |
| 来源时间未知／活动内容缺失 | 保留降级状态，不按外层时间或可见最小宽度补造开始结束。 |
| VoiceOver／辅助功能树 | 子成员活动读出正确所属名称和阶段；不能全部回退成“主智能体”。控件有完整名称和可用状态。 |
| 点击后独立活动查看器 | 原始参数／结果、分页、复制、选区和窗口复用仍正确；查看器默认布局不因面板紧凑而变。 |

成员状态只使用可靠的所选轮归属。缺少实时动作证据时，不得为了匹配示例显示“思考中 · 8s”等猜测值。

## 4. 轮次、统计与请求竞态

| 场景 | 通过标准 |
| --- | --- |
| 单轮、多轮、已结束聊天 | 原生轮次入口有清晰控件外观；标题区分本轮／最近／历史；不可用时不造菜单选项。 |
| 同聊天切历史轮再回当前 | 时间线、初始输入、成员范围与统计一起切换；聊天行仍表示聊天当前状态。 |
| 轮中 steering／回答 | 不自动变为新轮；初始输入浮层与后续用户输入标记职责明确。 |
| A → B 聊天或轮次，A 响应迟到 | A 不能覆盖 B 的轨迹、输入和统计；加载期间不会拿旧 bundle 当新内容。 |
| 输出／推理用量匹配，均速样本不匹配 | 仅用量显示值，均速显示 `—`；反向情况独立判断。 |
| 历史轮缺统计、已知零值 | 缺失用 `—`，已知零保留；不借当前轮样本，不对子成员用量求和。 |

检查的完整身份至少覆盖 scope、聊天／阶段线程、turn、phase，以及相应请求代次。界面中相同标题或相同阶段显示名不能让跨身份响应通过。

## 5. 原生缩放与滚动

- 右上角为原生减号、只读范围和加号，没有范围选择菜单或滑杆；减号缩小、可见时间更长，加号放大、时间更细，边界正确禁用。
- 参考视口的 30／60 秒档及不同绘图区宽度均检查一次，标签反映实际可见范围；不是整轮时长或 ETA。
- 手动阅读中缩放／窗口调整保持既有阅读锚点；跟随最新时保持最新，脱离跟随后可用“回到最新”。
- 列表纵向、轨迹纵向、时间横向及输入浮层滚动各自作用于正确区域；所有成员共用一次时间偏移，标签与轨道纵向同步。
- 改选聊天再选回时按该聊天恢复阅读上下文；新轮和重新展示的行为符合既有跟随规则，不串用另一聊天缩放。

## 6. 输入浮层、菜单与关闭

| 场景 | 通过标准 |
| --- | --- |
| 短输入、长输入、多页原始内容 | 可选择复制，长内容限高滚动；按来源分页，主面板高度不增加。 |
| 缺初始输入、未保留、截断、失败 | 入口可用性与文案明确；来源状态可见，不显示标题或其他轮旧文本冒充正文。 |
| 浮层内部点击、复制、滚轮 | 浮层可正常操作，不触发主面板外部点击关闭。 |
| Esc、浮层关闭入口、面板外点击 | Esc 先关子浮层；再次 Esc 可关面板；两者之外点击可同时关闭，未永久屏蔽外部关闭。 |
| 打开轮次原生菜单 | 选择和取消正常，不被主面板事件监听抢先关闭。 |
| 浮层加载时换聊天／轮次或关闭 | 任务失效，迟到响应不显示、不重新打开；不存在上一轮正文短暂闪现。 |

说明浮层若可交互，也检查相同窗口归属与关闭规则。该入口只读，不新增用户输入或审批功能。

## 7. 窗口与视觉层级

在日常显示器与较小可用高度各检查一次；跨显示器以当前菜单栏锚点所在屏幕为准。

- 正常情况下 5 行可见，少量聊天窗口相应缩短；大量成员时轨迹受限并可滚动。
- 小屏允许列表早于 5 行滚动，必要操作仍可达；无菜单栏遮挡、屏幕底部裁切或测量抖动。
- 标题、输入和缩放在 420 pt 内不互相遮挡；长标题／项目保持紧凑且可获取完整名称。
- 图例仅一份、位于整图下方左侧；统计为普通字号的一行，推理“含于输出”的关系清晰，无统计或轨迹选项展开。
- 展示量与选中态足以识别当前聊天，避免大号数字或多层卡片抢占阅读重点。
