# 活动时间线：验证与验收计划

日期：2026-10-17。状态：已按本计划执行针对性检查；结果、证据层次与残余范围见[验收记录](validation-results.json)和[实施结果](implementation-results.md)。

下列 T01–T19 保留首轮验收含义。后续改变事件标记、工具布局及原始详情，分别修订 T03、T06、T07、T11 等目标；本轮使用[后续计划中的 F01–F10](refinement-plan.md#61-针对性验收)，执行结果见[后续调整结果](refinement-results.md#本轮检查)，不把旧“通过”直接迁移为新规则已通过。

最新一轮取消缩放与顺延，改用 60／120 秒范围及重叠覆盖展开；对应检查单独记录于[最新布局验收](overlap-layout.md#验收记录)，此前 T／F 结论保留原范围。

之后比例规则改为菜单最多一分钟、详情与窗口大小变化保持同一比例；本轮检查见[固定时间比例](fixed-scale.md#本轮验证)，旧 60／120 秒方案结果不作为新比例的证据。

最新工具验收以[来源时间方案](true-time-tools.md#验收重点)为准：短线精确命中、长工具与连续短工具的局部选择、多工具独立读取／分页／失败及迟到响应。

## 1. 验证层次

| 层次 | 能证明什么 | 不能替代什么 |
| --- | --- | --- |
| V1 来源检查／脱敏真实样本 | 指定版本和记录中实际存在的字段、内容与关系 | 其他版本兼容性、完整实时链路 |
| V2 合成事件／历史夹具 | 幂等、乱序、身份、时钟、裁剪、错误和降级规则 | 实际生产通知会这样投递 |
| V3 模型／契约与布局测试 | 编解码、几何、命中、选择和状态保持 | 原生滚动、焦点、窗口生命周期 |
| V4 只读原生 Preview | 实际尺寸、浅／深色、点击与键盘、窗口交互 | 日常 writer 与观察生命周期 |
| V5 本机针对性运行 | 指定版本的实时→历史链路、采集和窗口关闭行为 | 长期使用、全版本、发行、跨机器与 Remote |

只做与本轮变化相关的回归。已有安装、用量计算和恢复事务的有效证据可以复用；代码边界被改动或出现失败时再扩大验证。

## 3. 针对性测试位置

已新增测试：

- Python `test_timeline.py`：事件阶段、状态点、身份与 provenance；`test_timeline_storage.py`：幂等、裁剪、恢复及无正文；`test_history.py`：格式、索引、分块、来源替换和降级。
- Swift `TimelineLayoutTests`：共同轴、视口、重叠 hit test、短事件与零时长；`TimelineStoreTests`：切轮、异步取消、阅读锚；查看器生命周期测试：复用、关闭与无管理副作用。
- 合成夹具覆盖不足时才补针对性例子，不为颜色常量、普通文案或静态排版逐项编写镜像实现的测试。
- 模型独立展示回归：思考 46 毫秒后间隔 3 毫秒输出，及模型边界交叠 22 毫秒时，均不得自动层叠；模糊点击直接打开对应详情，汇总行只收工具。结果见[模型阶段修正](fixed-scale.md#后续修正模型阶段独立展示)。

需重点保留的既有用例：

- [test_engine.py](../../tests/test_engine.py)：跨轮进程、未知身份不按最近项归属、参数准备不等于执行、镜像和断连。
- [test_file_editing.py](../../tests/test_file_editing.py)：晚到参数不覆盖 canonical 编辑、明确 call ID、文件名不建立身份、缺开始耗时未知。
- [test_progress_semantics.py](../../tests/test_progress_semantics.py)：派发结束不代表 child 完成、请求解决与等待语义。
- [test_overview.py](../../tests/test_overview.py)、[test_menu_presentation.py](../../tests/test_menu_presentation.py)及受影响的 usage 测试：指标与菜单栏边界。
- Swift 现有 snapshot／菜单栏／管理生命周期测试中被新数据接入和窗口协调触及的部分。

既有测试名中的 `background_command` 是历史命名，不构成本轮新增“后台工具轨”的产品依据。

## 4. 运行检查与记录

实现后按阶段运行相关 Python unittest；Swift 模型和 App 检查可沿用仓库既有命令：

```sh
swift test --disable-sandbox --cache-path .local/swift-cache --package-path macos
```

真实窗口测试需额外启用 `MONITOR_WINDOW_TESTS=1`，在 WindowServer 图形会话执行 `--filter viewerReusesWindowAndPreservesResizedFrameAcrossContentChanges`；常规受限测试会跳过该项。

原生验证先复用[独立预览机制](../../experiments/gui-redesign/README.md)，增加合成时间线及查看器场景，确认不会写入日常数据根。实际构建命令沿用 `bin/build-gui`，但构建成功不等于已经更新日常 App 或完成本机运行验收。

每项结果至少记录：需求／T 编号、代码版本、数据类型和版本、执行方式、观察结果、证据路径、剩余边界。真实样本报告只保留结构、计数、匿名关联及必要时间，不复制消息／参数／命令／输出。截图使用合成数据。

本轮完成只意味着该机器与指定版本下的时间线和窗口功能达到所列范围。公开发行、签名、公证、全新机器、长期自然使用和跨设备 Remote 不由这些结果自动覆盖。
